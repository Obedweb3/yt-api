🎬 YT Downloader API

YouTube138 · RapidAPI · Vercel Serverless

API is live

Search

GET/api/search
Search YouTube by song or video name — returns a list of results
?q — search query (required)
?type — video · channel · playlist  (default: video)
?limit — results count 1–20  (default: 10)
/api/search?q=Blinding+Lights&limit=5
GET/api/search-download⚡ one-shot
Search by name → picks top result → returns MP4 + MP3 download URLs in one call
?q — song or video name (required)
?quality — best · 1080 · 720 · 480 · 360  (default: best)
/api/search-download?q=Shape+of+You&quality=720

Video Info

GET/api/info
Video metadata — title, thumbnail, duration, channel, views
?url — YouTube URL or video ID (required)
/api/info?url=https://youtu.be/dQw4w9WgXcQ
GET/api/formats
All available formats grouped: combined, videoOnly, audioOnly
?url — YouTube URL or video ID (required)
/api/formats?url=dQw4w9WgXcQ

Download

GET/api/download-mp4
Returns a direct MP4 download URL
?url — YouTube URL or video ID (required)
?quality — best · 1080 · 720 · 480 · 360  (default: best)
/api/download-mp4?url=dQw4w9WgXcQ&quality=720
GET/api/download-mp3
Best audio stream URL (M4A — convert to MP3 with ffmpeg)
?url — YouTube URL or video ID (required)
/api/download-mp3?url=dQw4w9WgXcQ
GET/api/stream302 redirect
Redirects to Google CDN stream — triggers browser download directly
?url — YouTube URL or video ID (required)
?itag — format itag from /api/formats (required)
/api/stream?url=dQw4w9WgXcQ&itag=22

Health

GET/api/health
Server health check
/api/health

Common itags

18 → MP4 360p (video + audio) 22 → MP4 720p (video + audio) 137 → MP4 1080p (video only — no audio) 140 → M4A 128kbps (audio only) 251 → WebM 160kbps (audio only)
