🎬 YT Downloader API

YouTube138 · RapidAPI · Vercel Serverless

API is live — all endpoints operational

Endpoints

GET /api/info
Video metadata — title, thumbnail, duration, channel
?url — YouTube URL or video ID (required)
/api/info?url=https://youtu.be/dQw4w9WgXcQ
GET /api/formats
All available formats grouped: combined, videoOnly, audioOnly
?url — YouTube URL or video ID (required)
/api/formats?url=dQw4w9WgXcQ
GET /api/download/mp4
Returns a direct MP4 download URL
?url — YouTube URL or video ID (required)
?quality — best · 1080 · 720 · 480 · 360 (default: best)
/api/download/mp4?url=dQw4w9WgXcQ&quality=720
GET /api/download/mp3
Best audio stream URL (M4A — pipe through ffmpeg for .mp3)
?url — YouTube URL or video ID (required)
/api/download/mp3?url=dQw4w9WgXcQ
GET /api/download/stream 302 redirect
Redirects directly to Google CDN stream — triggers browser download
?url — YouTube URL or video ID (required)
?itag — format itag from /api/formats (required)
/api/download/stream?url=dQw4w9WgXcQ&itag=22
GET /health
Health check — returns status and timestamp
/health

Common itags

18 → MP4 360p (video + audio) 22 → MP4 720p (video + audio) 137 → MP4 1080p (video only) 140 → M4A 128kbps (audio only) 251 → WebM 160kbps (audio only)
